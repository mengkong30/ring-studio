# Ring Studio · 环带工作室

一个在浏览器中运行的三维环带编辑器。由此前的八张图表和 AE 动画曲线延伸而来，可实时调整角度、灯光与卡片页面。

## 在线使用

[打开环带工作室](https://mengkong.online/ring-studio/)。无需安装，也不用启动本地服务器。所有编辑与自定义图片仍保存在当前浏览器中，不上传到 GitHub。在线地址与本地地址的自动保存相互独立，可通过 `.ring.json` 项目文件迁移。

## 直接使用

电脑需要 Node.js 20 或更新版本。Windows 双击 **启动环带工作室.cmd**，浏览器会打开 `http://127.0.0.1:5186/`。保留启动窗口，关闭窗口会停止服务。发行包已经包含构建结果，使用时不用安装依赖，也不需要 AE、Figma 或登录账号。

若提示端口占用，请打开该地址查看已启动的编辑器，或关闭旧服务再启动。文件不能通过直接双击 `dist/index.html` 使用，需要上述本地服务。

## 操作

- **场景**：调整 X/Y/Z 角度、环带半径、页面高度、页面间距、画面大小、背景、内侧透明度、旋转速度和图表速度。拖动画布也能改变视角。负速度反转，0 停止环带。
- **灯光**：调整主光的方位、高度、强度、颜色，以及环境亮度、材质粗糙度。提供柔和日光、暖色侧光、冷色轮廓三种预设。
- **页面**：在左侧选中卡片，修改类型、标题、文案、数据及颜色。可添加、复制、移位或删除卡片；删除后提示中可撤销。支持最多 16 张卡片。
- **自定义页面**：上传 PNG、JPG、WebP 或简单 SVG，选择完整显示或铺满裁切。图片最大 10 MB，会在本地转为不超过 1440 像素的 PNG。SVG 不允许脚本或外部资源。上传的图片是一张静态页面；它会跟随环带旋转和受光，但无法直接修改图片内部文字。
- **保存项目**：导出 `.ring.json`，包含参数、卡片和上传图片；“打开项目”可恢复。浏览器同时自动保存在本机 IndexedDB。重要项目请另存文件；清理浏览器数据会清除自动保存。不同浏览器、不同本地端口各自存储。
- **导出图片**：导出当前三维画布的 PNG，不包含编辑面板。尺寸跟随预览画布和设备像素比。
- 底部可播放、暂停、回到起点或拖动 12 秒预览时间轴。默认每秒转 30°，12 秒一圈。其他速度的周期随速度改变；图表默认每 4 秒循环。速度不为 30° 时，12 秒预览刻度不代表环带完整一圈。

## 当前边界

这是浏览器网页项目，不自动同步修改到原 AE 工程。目前提供项目文件和 PNG 导出，尚未加入视频编码、云端协作或用户作品发布功能。三维预览需要 WebGL；色彩和灯光由 Three.js 实时渲染，与 AE 的 CC Cylinder 并非逐像素一致。

卡片中的数据为演示数据。没有账号、上传服务、统计追踪或远端字体请求；自定义图片的处理和保存发生在当前浏览器中。

## 开发

```sh
npm ci
npm run dev
npm run build
npm test
```

React + TypeScript + Vite + Three.js。界面使用轻量的本地表单组件与 Tailwind 主题，不依赖 UI 插件。`src/ae-timeline.json` 是从实际 AE 控制器以 120 Hz 采样的图表曲线；`src/chart-source.json` 保留原始矢量路径，折线图使用同一组贝塞尔曲线。

`Scene.tsx` 管理三维几何、纹理、灯光和播放；`charts.ts` 绘制图表；`model.ts` 定义及校验项目格式；`storage.ts` 负责本地保存和图片处理。

## 更新 GitHub Pages

仓库的 Pages 发布源设置为 `main` 分支的 `/docs`。修改源码后运行：

```sh
npm ci
npm test
npm run build
node prepare-pages.mjs
git add src docs package.json package-lock.json
git commit -m "Update Ring Studio"
git push
```

提交涉及的其他配置文件也应一起提交。GitHub 会自动重新发布，构建状态可在仓库 Actions 中查看。`docs` 是构建输出，应修改 `src` 后重新生成，避免直接修改压缩后的文件。GitHub 源码下载不包含 `dist`，本地启动前请先运行 `npm ci` 和 `npm run build`。
